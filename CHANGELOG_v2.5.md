# ACIS POS v2.5 — Modular Navigation & Multi-Tab Workspace

- Sidebar disederhanakan menjadi 7 kelompok modul agar tidak perlu scroll panjang.
- Klik kelompok modul membuka panel submenu bergaya aplikasi bisnis/ERP dengan kartu menu.
- Workspace mendukung multi-tab: menu yang sudah dibuka tetap tersedia sebagai tab.
- Tab dapat dipindah tanpa mencari ulang menu di sidebar, dan dapat ditutup (Dashboard dipin).
- Daftar tab disimpan di session browser selama sesi berlangsung.
- Navigasi mobile tetap didukung.
