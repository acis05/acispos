# ACIS POS v2.7.1

Perbaikan UI layar pembayaran Kasir (POS):

- Tombol pecahan uang dibuat lebih jelas dan rapi pada layar kasir.
- Tambah format pemisah ribuan di kolom **Jumlah Bayar** saat diketik.
- Input nominal bayar memakai tampilan `Rp` dan format angka Indonesia.
- Kalkulasi kembalian tetap realtime.
- Nominal yang dikirim ke backend tetap berupa angka murni.
